# Pinterest BoardFlow Downloader

面向 macOS + Chrome 的精简 Manifest V3 扩展。它只在 Pinterest 页面上收集静态图片，并通过 Chrome Downloads API 写入：

```text
~/Downloads/PinterestInbox/<board-slug>/<safe-title>__pin-<pin-id>.<ext>
```

**0.4.3 只更新公开名称：**扩展现名为 Pinterest BoardFlow Downloader，下载行为、权限、目录与 0.4.2 完全兼容。**0.4.2 连续点图排队已通过真实 Pinterest 验收：**单张模式下载过程中可以继续点第二、第三张，按点击顺序逐张处理；重复点击仍在提交/下载中的同一图版 Pin 不会重复入队。面板显示整组进度，取消覆盖全部未完成项。保留 0.4.1 的面板重绘恢复、0.4.0 的多选与界面优化。

更新已有扩展：在 `chrome://extensions` 找到旧名称 **Pinterest Inbox Downloader**（重新加载后显示为 **Pinterest BoardFlow Downloader**），点击重新加载，再刷新已打开的 Pinterest 页面。仅刷新网页不会加载新的后台程序。安装源仍是本目录。

## 本地加载

1. 打开 `chrome://extensions`；
2. 开启“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择本目录。

扩展进入 Pinterest 页面后显示小型操作面板：

- 收起/展开：折叠控制区，保留当前进度摘要；采集仍在运行，恢复正常浏览请使用“暂停”；
- 暂停/启用：暂停后 Pin 恢复 Pinterest 原本点击行为，并取消当前采集任务；
- 保存质量：原图、JPEG 高清或智能轻量；选择会保存在 Chrome 本地配置中；升级到 0.3.1 时会一次性迁移到默认智能轻量；
- 单张模式：连续单击 Pin，立即加入后台队列，按点击顺序逐张下载；
- 多选模式：勾选多个 Pin 后批量下载；
- 清空选择：一次移除所有勾选；提交失败会保留选择，可直接重试；
- 整板下载：自动滚动当前图版，收集完成后批量下载；
- 取消下载队列：取消正在处理的图片与本面板加入的后续等待项，已保存文件保留。

下载时显示整组的处理数量和已保存、跳过、失败三项统计；例如连续点三张，进度依次为 0/3、1/3、2/3、3/3。待处理包含正在下载与排队中的图片。进度条表示处理数量，完成不代表所有图片都保存成功，应以“已保存”数量为准。单张模式可继续点图追加；取消收尾期间暂不接受新图片。按住 `⌘` / `Ctrl` 点击继续使用网页原本的打开行为。下载期间仍不能切换模式/质量或启动整板扫描。

整板扫描期间切换到其他页面会停止本次扫描，避免把两个图版混在一起；未开始下载的扫描不会落盘。页面持续加载而达到安全上限时，会保留明确提示。

- 自动回归覆盖快速下载完成、下载编号尚未返回时取消、原图探测期间取消、失败重试、三档质量、偏好迁移、提交失败保留选择与过期进度隔离。
- 0.4.1 下载器回归 24/24 通过。真实 Chrome 的本地模拟页复现旧版节点移除后无法恢复；修复版通过面板/样式移除、body/html 整体替换、暂停/选择/任务保留及连续 12 次重绘检查。0.4.2 在真实登录态 Pinterest 页面加载、滚动和操作期间保持可见。
- 本地浏览器已检查多选/清空、虚拟列表重绘后的勾选、失败重试、收起进度、取消/暂停、扫描切页与整板收集、320/400/1200px、深色和减少动态效果。测试使用模拟 Pinterest 卡片与 Chrome 消息，并未下载真实 Pin。
- 人工验收结论：Chrome 管理页确认已启用版本 **0.4.2**，真实页面的连续点图、重复去重、整组取消和暂停恢复均通过。当前队列只在扩展内存中，不提供重启恢复；刷新网页会丢失面板对旧任务的进度跟踪，已提交后台的任务可能继续下载。

每张图先探测 Pinterest CDN `originals` 原图：优先原生 JPG/PNG，如果原图只有 WebP 则以 WebP 作为最高质量源。扩展不伪改后缀，也不回退到低分辨率缩略图。

质量选项：

- 原图：保留 originals 的原始分辨率、字节和格式；
- JPEG 高清：非透明素材使用原始分辨率 JPEG 90，用于兼容性，不承诺比 originals 更小；
- 智能轻量（默认）：WebP 原样保存；其他格式生成最长边 2048px、JPEG80 或透明 PNG 的候选件，只有候选件严格更小时才采用；
- 透明素材：JPEG 高清输出 PNG；智能轻量只有在透明 PNG 候选件更小时才采用。

高清和轻量使用 Chrome Offscreen 图片处理页面，不读取 Pinterest Cookie。图片处理失败会明确计入失败，不会偷偷改用页面缩略图。
文件名使用“标题在前、Pin ID 在后”，方便浏览并保持稳定去重，例如 `Modern Pink Dinosaur__pin-123456.jpg`。
标题优先读取 Pinterest 卡片的结构化标题节点，不把图片 `alt` 中的“其中包括图片”等无障碍描述写入文件名。
为避免 Chrome 退回 CDN 哈希名，扩展同时在下载请求和最终文件名确定事件中提交相同目标名。

视频 Pin、HLS、无有效 `pinimg.com` 地址或无可用 originals 原图的项目会被跳过。每个失败下载会自动重试一次；相同 Pin 使用确定性文件名和 `overwrite`，不会写入 `PinterestInbox` 以外的位置。
