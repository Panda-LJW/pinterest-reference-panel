# Pinterest BoardFlow 参考素材

## 打开与续用

用户已经选择或提及 Pinterest BoardFlow 插件时，未另行指定对象的“打开”意图指向正在运行的素材看板。例如 `@Pinterest BoardFlow 打开项目` 应启动看板。为兼容旧对话，`Pinterest Inbox` 也视为同一插件的旧称。只有用户明确要查看源码、文档或管理 Codex 项目时，才进入对应的开发/项目操作；此规则不接管其他项目的打开请求。

打开面板需要完成两个动作：

1. 调用插件的 `open_pinterest_inbox_web`。首次调用不传参数，会创建空参考篮；重新打开已有参考篮时传回本任务保存的 `referenceSessionId`。保留返回的 ID 和完整 URL，包括 `?ref=` 查询参数。
2. 用 Codex 的 `open_in_codex` 工具实际打开这个 URL，参数为 `target: { type: "browser", url: 返回的完整URL }`、`placement: "right"`，默认当前任务。若工具被延迟加载，先从可用工具目录查找。也可使用宿主提供的可见内嵌浏览器入口；不需要用桌面自动化点击 Codex 自身界面。

打开 README、定位仓库或只返回网页地址都不代表面板已经显示。浏览器工具返回已打开后才能报告“已打开”；若返回 `queued`，说明已排队，页面将在当前任务被显示时打开。若启动或浏览器工具不可用，准确说明停在哪一步并提供实际可用的 URL（已有时），不要改开文件并报告成功。不要手动启动第二个 InboxService 或 watcher 来绕过工具缺失。

面板支持完整本地库搜索、图版筛选、大图预览和最多 10 张有序参考图。点击图片打开预览，点击 ＋ 选择。用户主动回到对话描述需求后，再读取选择；页面操作本身不发送消息。

## 使用选中的图片

1. 用户说“使用选中的参考图”等请求时，调用 `get_pinterest_reference_selection`，传入本任务此前获得的 `referenceSessionId`。
2. 结果中的 `files` 是有序的本地原文件路径。保留 `revision` 与编号对应关系，用当前可用的图片查看工具实际读取这些文件后，再做视觉分析或生成。工具只返回文件信息，不能把文件名、标题或缩略图当作已经看过原图。
3. 生成图片时按当前可用生成工具的规则传入返回的本地路径；需要先查看图片时先查看。用户重新选图后重新读取参考篮，不复用过期列表。并发工作需要核对同组选择时，可传 `expectedRevision`；版本冲突时重新读取。

不能根据同一工作区、最近打开的面板或其他任务历史猜测参考篮 ID。上下文中缺少本任务 ID 时先查本任务已有工具结果；仍无法恢复则说明原因并重新打开空篮让用户选择。会话失效、空篮或原文件变化时，按工具错误提示恢复，不退回其他任务的选图。

## 路径复制备用

卡片、预览和参考篮提供路径复制，用户可手动粘贴到对话。不向输入框注入附件或文字，不自动发送，不修改长期库原文件。`render_pinterest_reference_panel` 与 `import_pinterest_reference` 是旧工作区导入流程，仅在用户需要该流程时使用。
