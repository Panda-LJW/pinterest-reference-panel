## 目标与范围

让用户在同一面板完成查找、看图和组合参考：搜索整个本地库，放大查看原图，选择最多 10 张有编号的图片，然后直接在发起面板的 Codex 任务中描述需求。Codex 通过只读工具读取明确的参考会话。路径复制继续可用。

## 页面与视觉

浅色为默认视觉基调，同时适配系统深色。使用细边框、紧凑工具栏、低干扰状态提示和保留原始比例的图片；小红色强调色仅用于当前标签与选中项。沿用原生 HTML/CSS/JavaScript、现有 MCP SDK 和唯一 InboxService。

```text
素材工作台
  顶栏：品牌 / 库状态 / 刷新 / 使用说明
  浏览工具：全部图片 / 图版 / 搜索 / 排序
  内容：结果数量 / 当前图版 / 图片网格或图版卡片 / 加载与重试
  大图对话框：原图 / 标题与格式 / 上一张下一张 / 加入参考 / 复制路径
  参考篮：有序缩略图 / 编号 / 移除与排序 / 清空 / 复制全部路径 / 使用提示
  全局反馈：非阻塞提示 / 断线恢复 / 文件变更提示
```

卡片点击打开预览，独立的“加入参考”按钮用于选图，卡片和预览提供复制路径。浏览不再暗中改变剪贴板。窄栏保留双列图片、紧凑搜索和可横向滚动的参考篮；极窄宽度单列，宽窗口自动增加列数。预览使用原生 dialog，支持 Escape、方向键、可见焦点和关闭后返回触发位置。

## 状态与接口

- 每次不带会话参数的 `open_pinterest_inbox_web` 创建独立随机 `referenceSessionId`，URL 带该 ID；重开已有参考篮必须显式传回 ID。所有会话共享唯一 HTTP 服务与 Inbox watcher。
- 不依据进程、工作区目录或“最后打开的面板”猜测当前任务。新增只读 `get_pinterest_reference_selection(referenceSessionId, expectedRevision?)` 必须显式指定会话，工具返回顺序、版本和经过边界复核的原图路径。原图内容由 Codex 后续读取；不承诺输入框原生附件注入。
- 会话在 MCP 进程内存中保存，页面刷新或停止/重开网页可复用；进程重启会明确报告失效。进程内最多保留 64 个参考会话，避免无限增长；不会在满额时偷偷淘汰另一个任务。
- HTTP 增加参考篮读取/替换、批量路径复制、按已索引 assetId 查看原图。替换必须携带 revision，冲突时不覆盖其他页面的新选择。参考项记录选择时的文件状态，丢失或变化时标记不可用并阻止整组引用，避免静默换图。
- 搜索和排序先作用于完整服务端索引，再分页。搜索匹配标题、图版和 Pin ID；排序为最新、最早、标题。保留旧分页、缩略图、单张复制和旧 MCP 导入接口。
- 每个 HTTP 服务使用独立会话 Cookie 名称，避免多个本地端口互相覆盖 Cookie；沿用 Host、Origin、CSRF、回环和路径边界校验。

## 自检与修正

| 风险 | 处理 |
| --- | --- |
| 图片动作含义不清 | 预览、加入参考、复制分别使用明确控件 |
| 底部遮住素材 | 为参考篮预留高度，极窄窗口隐藏次要状态并换行工具栏 |
| 搜索只查首屏 | 完整索引过滤后分页，并显示真实结果数 |
| 状态变化造成闪烁或焦点丢失 | 卡片局部更新，缩略图按需加载，过期请求不覆盖当前视图 |
| 选了图但模型读到另一组 | 显式会话 ID、有序编号、revision 及文件状态复核 |
